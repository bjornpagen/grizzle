   Every failing case is a bracketed class in unicode mode, from a one-byte source, before `$`, unanchored at the
   start. Each control passes: `^`, the v flag, no `$`, the y flag (which skips the end-anchor optimization), an atom

2. The cause, in V8 14.6.202.34's source (src/regexp/).
   - regexp-parser.cc, RegExpParserImpl<CharT>::ParseCharacterClass, non-v branch: a class's flags get
     IS_CERTAINLY_ONE_CODE_POINT under `if (sizeof(CharT) == 1) { // No surrogate pairs.`, the width of the pattern's
     source, not of the code points the class names. Under u a one-byte source names supplementary code points by
     `\u{...}` escapes (and by a pair of `\u` escapes, `\p{...}`, and /iu case closure).
   - regexp-ast.h, RegExpClassRanges::max_match(): 1 when is_certainly_one_code_point(), else 2. Such a class reports 1.
   - regexp.cc, RegExpImpl::Compile: for a pattern anchored at its end, not at its start, not sticky, whose max_match()
     is below kMaxBacksearchLimit (1024), `macro_assembler->SetCurrentPositionFromEnd(max_length)` starts the search
     max_length code units before the end. With max_length 1, the search starts inside the surrogate pair, and the
     class, which needs both code units, finds no match.
   - The observations agree: dot, `\p{...}`/`\P{...}` and the two-byte source build their classes without the flag and
     pass; the y flag and `^` skip the optimization and pass; `a?[...]$` and `[...]b?$` raise max_match to 2 and pass;
     `[...]{2}$` reports 2 where it needs 4 and fails on two supplementary code points.

3. The fix, on V8 main.
   - 7d259d7c2090bb38af1fd9f6ca67c6dc8b6f88d8, "Reland "[regexp] Fix IS_CERTAINLY_ONE_CODE_POINT for unicode-mode
     classes"", by Jakob Linke, reviewed by Patrick Thier, Cr-Commit-Position refs/heads/main@{#110562}, 2026-10-12;
     https://chromium-review.googlesource.com/c/v8/v8/+/8556177. It relands 2f7f93cf5c1035086dcdf9758b2e604adab44ca6
     (reverted the same day), Fixed: 571871980.
   - regexp-parser.cc (+5/-2): the flag is keyed on `!IsUnicodeMode()` in place of the source's width. Outside unicode
     mode a class always matches one code unit. Its message's example: "/x[\u{1F600}]$/u.test('x\u{1F600}') returned
     false". It adds test/mjsunit/regress/regress-571871980.js, end-anchored classes over supplementary code points
     from one-byte and two-byte sources, negated, /iu and \p{}, with the controls.
